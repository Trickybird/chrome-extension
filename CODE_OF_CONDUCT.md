# Code of conduct

The rule is short: behave the way you would want a stranger to behave in a thread you both have to
read. Assume good faith, keep it about the work, and leave the person out of it.

That settles almost everything. What it rules out is the rest: harassment, personal attacks, and
bigotry of any kind, in issues, pull requests, commit messages, or anywhere else this project
happens.

A maintainer acts on reports. That can mean editing or removing what was posted, and for anything
deliberate or repeated, ending someone's part in the project. Report it by email to
conduct@trickybird.com rather than in a public issue, so it can be handled before it spreads.
